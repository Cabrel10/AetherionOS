AetherionOS

A bare-metal x86_64 operating system written in Rust, featuring a complete ELF dynamic linker, TLS 1.3 network stack, ext2 filesystem, and Linux ABI compatibility layer.

Rust #![no_std] x86_64 Ring 0/3 TLS 1.3 ELF64 + ld-musl

System Architecture

💾 Boot & Memory

Limine v8.x bootloader with per-process PML4 page tables, KPTI isolation, and 2 MiB initial stack mapping.

Limine Protocol 4-Level Paging HHDM KPTI

📂 Filesystem

VirtIO-BLK driver with ext2 read-only filesystem. Supports symlinks, directory traversal, and inode-level access.

VirtIO-BLK ext2 Alpine rootfs VFS Layer

🔗 Dynamic Linker

Full ELF64 loader with PT_INTERP detection, interpreter loading at 0x7FC0_0000_0000, and Linux ABI auxiliary vector.

ld-musl PT_LOAD AuxV PIE/ET_DYN

🌐 Network Stack

Complete TCP/IP with DNS resolution, HTTP client, and TLS 1.3 (X25519 + AES-128-GCM + SHA-256).

VirtIO-Net TCP/IP DNS TLS 1.3

⚙ Process Management

Ring 3 userspace via IRETQ, per-process FD tables, fork/execve, preemptive scheduler, and signal delivery.

IRETQ Scheduler Fork/Exec Signals

🧠 Linux Compatibility

Linuxulator ABI layer implementing 200+ syscalls: mmap, mprotect, brk, arch_prctl, ioctl, and more.

200+ syscalls musl libc Python3 BusyBox
